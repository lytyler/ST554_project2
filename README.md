NCSU ST554 Spring 2026 Project 2

The purpose of Part 1 of the project is to create a data quality class in pyspark. The python class, called SparkDataCheck, 
wraps a Spark, SQL-style data frame and provides functionality for cleaning and validating the data frame. The purpose of 
Part 2 of the project is to test and demonstrate SparkDataCheck class on the provided data.
